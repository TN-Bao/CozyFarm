# Cozy Farm 🎮

Cozy Farm is a **farming prototype** developed using **Unity 2022.3 LTS**.  
The project focuses on building core farming mechanics such as planting, watering, crop growth, and harvesting while maintaining a clean, modular gameplay architecture.

---

## 🚀 Play the Game

▶️ **WebGL Demo (Playable in Browser)**  
https://ngocbao.itch.io/cozyfarm

🖥️ **Windows Build**  
Available for download on the itch.io page.

---

## 🎮 Gameplay Features

- Tile-based farming gameplay
- Crop planting and harvesting system
- Watering mechanic affecting crop growth
- Tool switching system
- Inventory system for collected crops
- Day progression system
- Clean UI with in-game HUD and menus

---

## 🕹️ Controls

| Action | Key |
|------|----|
| Move | WASD / Arrow Keys |
| Use Tool | Space |
| Switch Tool | Q |
| Open Inventory | I |

---

## 🛠️ Technical Highlights

- **Unity 2022.3 LTS**
- **Tilemap-based farming system**
  - Grid-based interaction
  - Tile state management
- **ScriptableObject Data Architecture**
  - CropData
  - ItemData
- **New Input System**
  - PlayerInput
  - Action Maps
- **Tool System**
  - Modular tool behaviors
  - Tool switching system
- **Crop Growth System**
  - Multi-stage crop growth
  - Time-based progression
- **Inventory System**
  - Item collection and storage
- Simple time/day progression system controlling crop updates
- UI system with platform-specific behavior  
  (WebGL vs Windows)
